# Mantix

Load tests that tell the truth, written in the TypeScript you already have.

Mantix is a load-testing and benchmarking tool inspired by Locust and k6. Tests are plain TypeScript
(async by default, with an optional Effect API), the engine is built on Effect, and the live dashboard
is a Foldkit app.

> Work in progress. The first working version is being built through pull requests.
